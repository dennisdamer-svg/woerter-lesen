# Wörter lesen

Eine kleine, iPad-optimierte Übungsseite zum selbstständigen Lesen einzelner Wörter.

## Starten

`index.html` in Safari öffnen. Zum ersten Öffnen muss die Seite erreichbar sein; die Wortlisten selbst werden anschließend im Browser gespeichert. Die Sprachausgabe ist eine Funktion des iPads.

## Auf dem iPad verwenden

1. Die Seite in Safari öffnen.
2. Auf **Teilen** tippen und **Zum Home-Bildschirm** wählen.
3. Die Verknüpfung wie eine App öffnen.

## Hinweise zur Sprachausgabe in Safari

Die Vorlesefunktion verwendet die eingebaute Web Speech API mit `de-DE` und wird ausschließlich durch den Vorlesen-Knopf gestartet. Das entspricht der iOS-Safari-Vorgabe, dass Sprachausgabe eine direkte Nutzeraktion braucht. Die Sprachsynthese wird in Safari auf iOS seit Version 7.1 unterstützt; die aktuellen Kompatibilitätsdaten stufen sie als breit verfügbar ein ([MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)). Auf verwalteten iPads sollte in den Einstellungen eine deutsche Stimme aktiviert sein. Falls einmal keine Stimme kommt: Lautstärke prüfen, die Seite neu öffnen und den Vorlesen-Knopf erneut antippen.

Eigene Listen werden nur im Browser dieses iPads gespeichert. Werden Safari-Websitedaten gelöscht oder ein anderes iPad benutzt, sind sie nicht automatisch vorhanden.
